NetMon 1.0.1 improves the Windows layout for smaller displays and restores the intended large summary counters.

A polished, standalone Windows edition of the original NetMon network and Bluetooth monitor.

- Refreshed interface, summary cards, searchable/sortable device tables, CSV export, and Activity history.
- Persistent labels stored in your Windows user profile; no Python installation required.
- Select a local adapter, stop scans, and keep optional 30-second rescans running.
- Bounded hostname lookup, clearer error recovery, persistent Bluetooth event loop, and accurate adapter labeling.
- Vendor data, runtime dependencies, version metadata, and a custom app icon bundled with the executable.

**Download:** `NetMon.exe` is the single-file app. The ZIP includes the same executable plus notices, dependency versions, and validation details. Windows 10/11 x64. Unsigned binary.

**Validation:** regression tests plus source and packaged-executable integration checks. Physical network/Bluetooth hardware remains dependent on the PC and its permissions. Devices used by automated GUI tests are synthetic.
